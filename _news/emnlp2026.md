Excited to announce seven papers accepted to EMNLP 2026, three to the main conference and four to Findings! Main conference: [Who is the Agent to Blame?](https://arxiv.org/abs/2608.24306): localizing faithfulness and citation mistakes in agentic deep research. [How Well Do Vision-Language Models Understand Movies?](https://arxiv.org/abs/2506.06275). [FrankenReport](https://arxiv.org/abs/2609.06320): early exiting in long-form generation using expected value of computation. Findings: [PragReST](https://arxiv.org/abs/2606.18624): self-reinforcing counterfactual reasoning for pragmatic language understanding. [Balancing Faithfulness and Performance in Reasoning via Multi-Listener Soft Execution](https://arxiv.org/abs/2602.16154). [A History-Aware Visually Grounded Critic for Computer Use Agents](https://arxiv.org/abs/2606.11078). Debug or Regenerate?: test-guided selection for LLM code repair.
